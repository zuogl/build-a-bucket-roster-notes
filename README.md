# A first Classic or All-Time run in Build a Bucket

Pick a role before the first spin. Guard and Big each use ten attribute slots to build one basketball player. In Classic, the wheel draws from current players. All-Time draws from NBA legends.

1. Spin and inspect the attributes available from the player on screen.
2. Choose one attribute. Selecting Jump Shot fills that slot, leaving nine choices after the first pick.
3. Record the player, slot and visible grade. On a Guard board, watch for Passing, Handles and Perimeter Defense. The Big board has Rebounding, Playmaking and Interior Defense in those positions.
4. Repeat for the remaining slots and record the final OVR the game displays.

Salary Cap uses a separate five-category budget board. Keep those runs in a separate set of notes so a spending decision does not get confused with a Classic attribute pick.

The independent guide shows [how to play Build a Bucket](https://buildabucket.site/guide/how-to-play), including what happened on two successive picks in a recorded Guard Classic run.
