# Build a Bucket Basketball — 10-Slot Roster & Rules Reference

An unofficial community reference summarizing the core 10-slot roster structure and rating checkpoints for the Build a Bucket basketball drafting game.

## Core Checklist

- **Roster slots**: Track guard and big slots separately so no position group is left under-weighted.
- **Tier & trait balance**: Review visible tiers and traits across your lineup rather than relying on one high-OVR pick.
- **Mode differences**: Account for rule changes between Classic, All-Time, Salary Cap, and Sandbox sessions (and note that NFL Build a Bucket uses different rules).

For full rule breakdowns covering the 10 slots and OVR ratings, see [how to play Build a Bucket](https://buildabucket.site/guide/how-to-play).
